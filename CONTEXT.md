# NCERTCHEM

A visual-first learning site for Class 11 and 12 chemistry. It follows the NCERT syllabus and structure but teaches through animations and simulations rather than text alone. The product name is NCERTCHEM (chosen 2026-11-17; the working title was "Chemistry, Revisited"). The project is independent of NCERT: it is not affiliated with or endorsed by NCERT, and the site says so wherever the name could suggest otherwise.

## Language

### Audience

**Learner**:
A Class 11 or 12 student preparing for CBSE/state board exams, who is studying NCERT chemistry alongside this site.
_Avoid_: User, aspirant (JEE/NEET aspirants are not the primary audience)

**Teacher**:
A secondary audience who projects Animations and Simulations in a classroom.

### Content structure

**Unit**:
A top-level division that maps one-to-one to an NCERT textbook unit (e.g. Class 11, Unit 2 "Structure of Atom").
_Avoid_: Chapter (NCERT itself says "Unit"; use that word to stay aligned)

**Section**:
A numbered subdivision of a Unit that mirrors the NCERT section number (e.g. 2.4 "Bohr's Model for Hydrogen Atom"), so a Learner can move between book and site directly.
_Avoid_: Topic, lesson

**Syllabus Map**:
The complete list of Units for both classes, shown to Learners whether or not a Unit is live yet.

**Hook**:
The opening question or puzzling observation that starts every Section.

**Key Ideas**:
The 3–5 point revision summary that closes every Section.

**NCERT reference**:
The NCERT class, unit and section number that a piece of site content corresponds to. The site cites NCERT. It never reproduces NCERT text.

**Showcase Unit**:
The first Unit built completely, to the full quality bar, to prove the concept. Currently Class 11, Unit 1 (Some Basic Concepts of Chemistry). Section 2.4 (Bohr's model) was built earlier as a pilot.

### Visual content

**Animation**:
A guided, linear visual that the Learner plays or scrubs through. The author controls the narrative, and the Learner controls only the playback.
_Avoid_: Video, GIF

**Simulation**:
An interactive model where the Learner changes inputs (sliders, toggles, drag) and sees the system respond. The Learner controls the experience.
_Avoid_: Interactive, demo, widget

**Flagship Simulation**:
One of the few high-investment Simulations in a Unit, chosen because the concept is best understood by experimenting with it.

**Scrolly Animation**:
An Animation pinned beside the Prose, where scrolling through the Prose advances it.
_Avoid_: Scrollytelling (fine in conversation, but the artifact is an Animation)

**Step**:
One discrete state of an Animation, tied to a single passage of Prose. Animations advance Step by Step.
_Avoid_: Frame, slide, scene

**Check**:
A short question embedded in a Section that lets the Learner confirm understanding. It may be interactive (drag, select, build), but it is never graded or recorded beyond the Learner's own browser.
_Avoid_: Quiz, test, exercise ("exercise" means NCERT's end-of-unit questions)

**Visual Vocabulary**:
The single, fixed way each chemistry entity (electron, proton, nucleus, photon, energy level, orbital…) is drawn everywhere on the site, so the same thing always looks the same.
_Avoid_: Style guide, theme (those cover UI, not chemistry entities)

**Prose**:
Original explanatory text written for this site (never copied from NCERT) that frames and connects Animations and Simulations within a Section.
